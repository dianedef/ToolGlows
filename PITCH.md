# ToolGlows — Pitch

> Pitch reviewed: 2026-09-02 · Project state: see canonical sources below

ToolGlows is a configurable Chrome and Firefox toolbar that brings recurring reading, capture, search, navigation, and focus actions directly into the current web page. It helps browser-heavy professionals reduce context switching without turning the extension into a generic automation platform.

## Current state

The shared Vue/TypeScript Manifest V3 foundation, configurable toolbar, browser builds, persistence, and stable page-level utilities are in active development; Gmail, Instagram, and social-analysis modules remain experimental pending dedicated browser proof.
