## Voice

Practical, concise and reassuring. Lead with the action the user can complete. Avoid presenting the product as an all-in-one suite or overstating experimental integrations.

## Naming rule

Use `ToolGlows` for the product name in public UI, manifests, repository documentation and future store listings. Use lowercase `toolglows` consistently for technical namespaces, storage keys, CSS selectors and package identifiers.
