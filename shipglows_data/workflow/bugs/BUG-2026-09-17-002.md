# Bug Record: BUG-2026-09-17-002

## Summary

Rich Copy copies browser tab URLs; Auto Copy owns selected page text. Bounded direct repair, regression-first. Status remains `fix-attempted` pending actual browser verification; no build, deployment, commit or push was performed.

## Reproduction

1. Open Rich Copy from the toolbar with a page text selection present.
2. Choose current tab; expect the browser API tab URL, independent of the selected text or document URL.
3. Highlight multiple browser tabs in the same window and choose selected tabs; expect their URLs in tab order, one formatted entry per line.

## Expected Behavior

Browser background APIs supply titles and URLs. Current/selected/group queries remain in the initiating content script's window. Selected means browser-highlighted tabs. Existing saved formats remain available; URL uniquement yields bare URLs. Groups are available where the browser supports their API.

## Observed Behavior

Current-tab copying used document.title/window.location; malformed template literals prevented composable parsing, malformed Vue attributes prevented correct actions, and dialog visibility did not follow the toolbar-controlled prop. Background group queries could widen invalid IDs into the whole window.
