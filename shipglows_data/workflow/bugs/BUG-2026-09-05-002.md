# Approved scope and reproduction

The operator approved repairing the two defects found during comparison with
[Rich URL](https://richurl.madewithlove.in.ua/en/thank-you/). Rich HTML clipboard
payloads are a separate product change and are excluded. Automatic selection
copy remains exact plain text; only explicit format shortcuts are affected.

- Select text, press Alt+H with source enabled. The first URL is substituted,
  but the source link label remains literally `{url}`.
- Select `<strong class="emphasis">A &amp; B</strong>`, press Alt+M with
  formatting enabled. Actual output contains `A &amp; B` rather than `**A & B**`.

# Evidence and proof path

Regression-first. Initial audit: 16 existing cases pass; both additional
reproductions fail. The browser audit did not complete: the original runner
missed a transient fade state and its diagnostic retry was stopped after
stalling. Those runs do not establish browser compatibility.

Retest uses the rebuilt extension with a disposable browser profile and real
clipboard paste, plus unit regression tests and the repository baseline checks.
No personal browser profile is used and no manifest permission is added.

# Repair and retest

Template replacement is now global and uses a single callback pass, so inserted
content containing `{url}` or replacement-string syntax remains literal.
Markdown conversion traverses the detached cloned selection instead of matching
HTML with regular expressions or reparsing a serialized string. Editable values
are represented by text nodes, preserving literal markup and entity syntax.

Eight durable regressions were added. Seven failed before the initial repair;
the editable-field case then independently reproduced a regression before its
repair. Final focused retest: 24/24 passed. Full suite passed 258/258 before the
equivalent direct-node traversal refinement; focused retest after it also passed.
Final builds passed for Chrome and Firefox after the direct-node refinement.
Final typecheck passed. Firefox manifest lint: zero errors, 11 pre-existing
warnings; the intermediate extra parser warning was removed by direct traversal.

Real clipboard paste passed for HTML source URL (both occurrences), Markdown
emphasis/entities, and plain-text shortcuts in Chromium 151.0.7922.34 and Firefox
153.0. Firefox used the already installed matching Playwright runtime through
`PLAYWRIGHT_MODULE`, temporary remote addon installation and toolbar activation.
The test gives focus to the selected host element before the keyboard shortcut;
an earlier harness attempt incorrectly left focus inside the excluded toolbar.
Both final browser runs completed with `ok: true` and disposed of their profiles.

Verification scope is these formatting defects on the synthetic public-page
fixture, not all sites, visual feedback, the user's installed copy, or rich MIME
clipboard support. No product permission, dependency, UI or public claim changed.
Architecture and developer documentation are aligned. Changes remain local;
no commit, push or publication was performed in this task.
