# Bug Record: BUG-2026-08-30-001

## Summary

ToolGlows could recolor a site's fields while page dark mode appeared disabled. Generic PrimeVue CSS escaped the extension UI boundary, and removing Dark Mode from loaded tools did not guarantee that persisted runtime state was disabled.

## Expected Behavior

With page dark mode off, ToolGlows changes no host-page colors. Removing Dark Mode also persists the disabled state and cleans all injected dark-mode DOM state.
