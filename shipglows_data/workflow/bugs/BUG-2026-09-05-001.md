# Reproduction and expected behavior

Open extension setup/update, then activate ToolGlows dark mode on a web page.
Exercise a settings/tool update across the background bridge. Expected: setup
loads, dark mode activates, and synchronization completes without extension
preload warnings, forbidden inline execution or premature transaction failures.

# Diagnosis and repair attempts

2026-09-05: Vite module preloads are not reusable across the extension's browser
execution worlds. Disabled generated module preloads in the common build;
normal JavaScript imports remain.

2026-09-05: the pinned DarkReader API unconditionally inserts its inline proxy.
Both proxy options alone did not stop insertion. A tracked pnpm patch makes
insertion conditional, and the engine disables both proxies. CSP remains
unchanged. Existing blocked Chromium behavior is retained without the forbidden
attempt; CSSOM/custom-element proxy hooks are not supported in this mode.

Package installation reused cached packages and upgraded no versions. It also
removed stale lockfile entries for tesseract.js and its unused dependencies,
consistent with the pre-existing package.json removal.

Bridge transaction repair is integrated in this same bounded console defect.
The receiver acknowledges routing without waiting for its handler to complete,
so a paused receiver no longer causes a false transaction-ending failure.
