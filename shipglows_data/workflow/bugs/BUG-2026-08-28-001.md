# Bug Record: BUG-2026-08-28-001

## Summary

- Title: Toolbar stays on loading state in a fresh extension profile.
- Current status: `fixed-pending-verify`
- Severity: `high`
- Owner: Diane
- Next step: Browser retest in the local Edge unpacked-extension environment.

## Reproduction

- Preconditions: a newly loaded unpacked extension with no `toolglowsSettings` value in sync storage.
- Steps:
  1. Load the Chrome build in Edge as an unpacked extension.
  2. Open a normal HTTPS page.
  3. Wait for content-script initialization.

## Expected Behavior

The toolbar initializes its default settings, registers the available tools and renders the main ToolGlows button.

## Observed Behavior

The content script injects `#toolglows-root`, but it remains on `⌛ Chargement…` and exposes no tool controls.

## Evidence

- Playwright browser evidence on `https://example.com/`; no user data, accounts or private page content was used.
- Content-script log sequence: settings store created -> no settings found -> no subsequent tool initialization.
